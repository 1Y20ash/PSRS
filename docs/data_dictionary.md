# Data Dictionary

The following logical entities are planned and are not implemented in Phase 1:
- Items
- Locations (fictional coordinates only)
- Inventory Events
- Demand History
- Road Nodes and Road Edges (fictional network)
- Vehicles and Deliveries
- Weather Scenarios (synthetic)
- Forecast Results
- Planning Scenarios

Evaluation-only ground truth must be stored separately from algorithm-visible inputs. Field-level schemas will be added alongside synthetic data generation.
